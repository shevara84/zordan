# 🎭 Playwright Automation Project

[![Playwright Tests](https://github.com)](https://github.com)
[![GitHub Pages Deployment](https://shields.io)](https://github.io)

Ovaj repozitorijum sadrži E2E testove u **Playwright** framework-u sa **TypeScript**-om i **POM** arhitekturom.

👉 **[POGLEDAJ PLAYWRIGHT HTML IZVEŠTAJ](https://github.io)**

## 🛠️ Tehnologije
- **Playwright**, **TypeScript**, **Page Object Model (POM)**, **GitHub Actions** (CI/CD sa 2 paralelna workera).

## 💻 Lokalno Pokretanje
1. Kloniranje:
```bash
git clone https://github.com && cd zordan
```
2. Instalacija:
```bash
npm ci && npx playwright install --with-deps
```
3. Pokretanje testova:
```bash
npx playwright test
```
4. Izveštaj:
```bash
npx playwright show-report
```
